# NUNLauncher — Aura mobile environment

A standalone mobile-first launcher concept with its own visual language and interaction model.

## Visual direction

NUNLauncher is intentionally expressive and consumer-facing: midnight indigo, lavender, atmospheric cyan and soft coral. The design uses layered celestial geometry, a custom clock widget, colourful tactile app tiles and translucent control surfaces. It does not reuse the NUN engineering-console layout.

## Preview

Open `index.html` in a modern browser. Desktop browsers display a phone-sized viewport; mobile browsers fill the screen.

## Included

- Distinct home screen, time/date widget, app shortcuts and favorites dock.
- Searchable app library with All, System, Creative and Daily categories.
- Quick-control panel with locally simulated toggles and screen-brightness presentation.
- Contextual greeting, local clock, drawer transitions and touch pull-down gesture.
- Original CSS-generated celestial and anime-inspired atmosphere without external image dependencies.
- Tactile app-icon states, layered shadows, pressed controls and reduced-motion support.

## Boundaries

This is a web-based interaction prototype, not a native Android APK. App shortcuts open local preview dialogs. Wi-Fi, Bluetooth, flashlight and brightness controls do not change actual Android settings. A native Android implementation and device integration remain future work.


## Abstract layout interpretation

The sketch is translated into a mobile-first canvas: status strip at the top, a large personal home field, floating celestial accents and widget geometry, a searchable app collection, a pull-up library, quick-control sheet and a bottom favourite dock. Aura keeps its midnight indigo, lavender, cyan and coral identity; the spatial composition is shared, not the palette or desktop navigation model.
